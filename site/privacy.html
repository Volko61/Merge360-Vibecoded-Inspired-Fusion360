Politique de confidentialité — Merge360

Dernière mise à jour : 19 octobre 2026

Merge360 est un logiciel de CAO 3D libre et open source (licence MIT), développé par Volko61. Le code source est public : https://github.com/Volko61/Merge360-Vibecoded-Inspired-Fusion360

Résumé

Merge360 ne collecte, ne transmet et ne vend aucune donnée personnelle. L'application fonctionne entièrement hors ligne : pas de compte, pas de publicité, pas de télémétrie, pas d'analytique, pas de rapport de plantage envoyé automatiquement.

Données stockées sur votre appareil

  • Vos fichiers de conception (.m360, exports STL/STEP/SVG) sont enregistrés uniquement aux emplacements que vous choisissez.
  • La liste des fichiers récents (chemins d'accès) est enregistrée localement dans un fichier recent.txt du dossier de configuration de Merge360, pour afficher le menu « Récents ». Vous pouvez supprimer ce fichier à tout moment.

Ces données restent sur votre appareil et ne sont jamais envoyées au développeur ni à un tiers.

Connexions réseau

Merge360 ne se connecte pas à Internet pendant son utilisation normale. La seule exception est la commande de mise à jour (merge360 --update), que vous lancez vous-même : elle utilise winget (Microsoft) sous Windows ou télécharge le script d'installation depuis GitHub sous Linux. Ces services appliquent leurs propres politiques de confidentialité. Les mises à jour distribuées par le Microsoft Store sont gérées par Microsoft.

Partage avec des tiers

Aucune donnée n'est partagée, puisqu'aucune donnée n'est collectée.

Enfants

Merge360 ne collecte aucune donnée, y compris auprès des enfants de moins de 13 ans.

Modifications

Toute modification de cette politique sera publiée dans ce fichier, dans le dépôt GitHub du projet, avec une nouvelle date de mise à jour.

Contact

Pour toute question : ouvrez une issue sur https://github.com/Volko61/Merge360-Vibecoded-Inspired-Fusion360/issues

Privacy Policy — Merge360 (English)

Last updated: October 19, 2026

Merge360 is free, open-source (MIT) 3D CAD software by Volko61.

Merge360 does not collect, transmit or sell any personal data. It runs fully offline: no account, no ads, no telemetry, no analytics, no automatic crash reports.

  • Your designs and exports are saved only where you choose.
  • A list of recently opened file paths is kept locally in recent.txt in Merge360's configuration folder. You may delete it at any time. It never leaves your device.
  • The app makes no network connections during normal use. The only exception is the update command (merge360 --update), which you start yourself; it uses winget on Windows or downloads the install script from GitHub on Linux, each subject to its own privacy policy. Microsoft Store updates are handled by Microsoft.
  • No data is shared with third parties, because none is collected.
  • Changes to this policy will be published in the project's GitHub repository.
  • Contact: https://github.com/Volko61/Merge360-Vibecoded-Inspired-Fusion360/issues
